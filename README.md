# Orbit Studio

Orbit Studio is a fictional small creative studio that designs websites for small businesses. This responsive website presents its services, sample projects, and contact form.

## About This Project

Developed for **Devixo Solutions – Web Development Internship, Task 02: Interactive Business Website**. The task focuses on building a responsive multi-page business website with JavaScript interactions.

## Technologies Used

HTML5, CSS3, and Vanilla JavaScript.

## Features

- Home, About, Services, Portfolio, and Contact pages
- Responsive navigation, hero image slider, and dark mode
- Portfolio filters, animated counters, and scroll-to-top button
- Contact form validation
- FAQ disclosures using native HTML

## Running Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
